# 🎵 方块跳跃音频可视化 - 技术方案文档

## 📋 概述

这是一个基于 **Three.js + React** 的音频可视化组件，实现了 8×8 方块网格随音乐节奏跳动的效果，并配有可爱的兔子精灵站在方块上弹跳。

---

| 技术 | 版本 | 用途 |
|------|------|------|
| React | 18.x | UI 框架 |
| Three.js | 0.160+ | 3D 渲染引擎 |
| TypeScript | 5.x | 类型安全 |
| Web Audio API | - | 音频频率分析 |
| SimplexNoise | three/examples | 柏林噪声生成 |

## 📥 输入参数

### Props 接口定义

```typescript
interface CubesVisualizerProps {
  analyser: AnalyserNode | null;  // Web Audio API 分析器
  isPlaying: boolean;              // 播放状态
  params: CubesParams;             // 用户可调参数
  colorTheme: CubesTheme;          // 配色主题
  uiBottomInsetPx?: number;        // 底部UI偏移量
}

interface CubesParams {
  height: number;      // 跳跃高度倍数 (0.5 ~ 5.0)
  spread: number;      // 频率扩散系数 (控制中心/边缘响应)
  damping: number;     // 阻尼系数 (0.05 ~ 0.5)
  showRabbits: boolean; // 是否显示兔子
}

type CubesTheme = 'pink' | 'purple' | 'green';
```

### 音频输入

- **数据来源**: `AnalyserNode.getByteFrequencyData()`
- **FFT 大小**: 256 (输出 128 个频率 bin)
- **数据范围**: 0-255 (Uint8Array)
- **采样频率**: 每帧获取一次

### 自定义 Shader

#### 顶点着色器

```glsl
varying float vWorldY;
varying vec3 vWorldNormal;

void main() {
  vec4 worldPosition = modelMatrix * vec4(position, 1.0);
  vWorldY = worldPosition.y;
  vWorldNormal = normalize(mat3(modelMatrix) * normal);
  gl_Position = projectionMatrix * modelViewMatrix * vec4(position, 1.0);
}
```

#### 片元着色器

```glsl
uniform vec3 colorBottom;
uniform vec3 colorTop;
uniform float maxHeight;

varying float vWorldY;
varying vec3 vWorldNormal;

vec3 linearToSRGB(vec3 linear) {
  return pow(linear, vec3(1.0/2.2));
}

void main() {
  // Y坐标 → 颜色渐变
  float t = clamp(vWorldY / maxHeight, 0.0, 1.0);
  float smoothT = t * t * (3.0 - 2.0 * t); // smoothstep
  vec3 baseColor = mix(colorBottom, colorTop, smoothT);
  
  // 面光照 (模拟右上方光源)
  float topFactor = smoothstep(0.5, 1.0, vWorldNormal.y);
  float rightFactor = smoothstep(0.5, 1.0, vWorldNormal.x);
  float brightness = 1.0 + topFactor * 0.15 + rightFactor * 0.05;
  
  vec3 color = min(baseColor * brightness, vec3(1.0));
  gl_FragColor = vec4(linearToSRGB(color), 1.0);
}
```

**效果说明**:
- 方块底部 → 饱和色
- 方块顶部 → 浅色
- 顶面亮度 +15%，右侧面 +5%，左侧面基准亮度

## 🎵 音频响应算法

### 频率映射逻辑

```typescript
// 1. 计算方块到中心的距离
const distance = Math.sqrt(x * x + z * z);
const normalizedDistance = distance / maxDistance;

// 2. 距离 → 频率索引 (中心=低频, 边缘=高频)
const spreadFactor = 1.0 / Math.max(0.1, params.spread);
const frequencyIndex = Math.floor(
  Math.pow(normalizedDistance, spreadFactor) * audioData.length * 0.4
);

// 3. 获取频率值并应用指数曲线增强对比
const rawValue = audioData[frequencyIndex] / 255.0;
const audioValue = Math.pow(rawValue, 2.5);

// 4. 柏林噪声叠加 (增加自然随机感)
const noiseVal = (noise.noise3d(x * 0.2, z * 0.2, time * 0.5) + 1) * 0.5;
const maskedAudioValue = audioValue * (0.4 + 0.6 * noiseVal);

// 5. 计算目标高度
const baseScale = 0.3 + noiseVal * 0.4;
const targetScale = baseScale + maskedAudioValue * params.height * 10.0;

// 6. 阻尼平滑过渡 (帧率无关)
const alpha = 1 - Math.pow(1 - params.damping, frameScale);
const newScale = THREE.MathUtils.lerp(currentScale, targetScale, alpha);

// 7. 应用到方块
cube.scale.y = newScale;
```

### 闲置动画 (无音频时)

```typescript
audioValue = (Math.sin(distance * 0.5 - time * 2.0) + 1.0) * 0.05;
```

## 🐰 兔子物理系统

### 物理参数

```typescript
const RABBIT_Y_OFFSET = 0.6;           // 脚部偏移
const MAX_RABBIT_HEIGHT = 6.0;          // 安全高度上限
const RABBIT_GRAVITY_PER_SEC2 = 216;    // 重力加速度 (units/sec²)
const RABBIT_AIR_DAMP_LOG_PER_SEC = -1.8; // 空气阻力系数
const RABBIT_JUMP_TRIGGER_VY_PER_SEC = 6; // 跳跃触发阈值
const RABBIT_POP_VY_PER_SEC = 21.6;     // 弹起初速度
const RABBIT_BOUNCE_DAMPING = 0.22;     // 弹跳衰减
```

### 状态机

```
┌─────────────┐
│   站立状态   │ ← isJumping = false
│  (idle)     │   velocityY = 0
└──────┬──────┘   跟随方块顶部
       │
       │ 方块上升速度 > 阈值
       ↓
┌─────────────┐
│   跳跃状态   │ ← isJumping = true
│  (jumping)  │   显示 up/down 纹理
└──────┬──────┘
       │
       │ 空气阻力: velocityY *= exp(dampLog * dt)
       │ 重力: velocityY -= gravity * dt
       │ 位置: y += velocityY * dt
       ↓
┌─────────────┐
│   落地碰撞   │
└──────┬──────┘
       │
       ├─ 速度 > 阈值 → 小幅弹跳 (velocityY *= -0.22)
       │
       └─ 速度 < 阈值 → 恢复站立状态
```

### 纹理切换

| 状态 | 纹理 |
|------|------|
| 站立 | `idle` (正常姿态) |
| 上升 | `up` (跳跃姿态) |
| 下落 | `down` (下落姿态) |

## ⚡ 性能优化

### 1. 帧率无关动画

```typescript
const BASELINE_FPS = 60;
const MAX_DT = 1 / 30; // 防止切换标签页后的帧跳跃

let dt = (now - lastNow) / 1000;
if (dt > MAX_DT) dt = MAX_DT;
const frameScale = dt * BASELINE_FPS;

// 阻尼计算使用时间因子
const alpha = 1 - Math.pow(1 - damping, frameScale);
```

### 2. 共享资源

- 所有 64 个方块共享同一个 `BoxGeometry`
- 所有方块共享同一个 `ShaderMaterial`
- 减少 GPU draw call

### 3. 像素比限制

```typescript
renderer.setPixelRatio(Math.min(window.devicePixelRatio, 2));
```

## 🎯 总结

这是一个**轻量级、高性能**的音频可视化方案：

1. **输入简单**: 仅依赖 Web Audio API 的 FFT 数据，无需复杂的 MIR 分析
2. **渲染高效**: 共享几何体/材质 + 自定义 Shader
3. **动画流畅**: 帧率无关的物理模拟 + 阻尼平滑
4. **视觉丰富**: 渐变配色 + 面光照 + 雾效 + 兔子动画
5. **可扩展**: 支持多配色主题切换
